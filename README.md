# Event Management System

## About
A web-based application designed to simplify college event management. It allows organizers to manage events and participants to search for events, register, and view schedules. It uses Data Structures and Algorithms to improve efficiency.

## Features
- Create and manage events
- Search events by name
- Detect venue scheduling conflicts
- Manage registrations and seat availability
- Handle waitlists and cancellations
- Display upcoming events

## Technologies Used
- Python
- Flask
- HTML, CSS, JavaScript
- SQLite

## Data Structures Used
- **Hash Table:** Fast event lookup
- **Trie:** Event name searching
- **Min-Heap:** Managing upcoming events
- **Queue:** Waitlist management
- **Binary Search:** Venue clash detection
